# Encapsulation

# Its a simple example of encapsulation

# Encapsulation is wrapping up of data into a single unit called class.

# Use of encapsulation is in our example is aircrafts fuel level as it is not accessible to outside world except the pilot who is         operating this flight.
# If the fuelLevel is public so anybody can change its level and if this kind of scenario happens aircraft will show false data to pilots to avoid this we kept fuelLevel as private and accessed it by using setFuelTank() and getFuelTank() member functions of same class which are public.
